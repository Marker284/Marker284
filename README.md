Держу дома личный сервер: Home Assistant, медиатека, Matrix, VPN - всё своё, ничего в облаке.
Устройства в основном самодельные - ESPHome на ESP32, Zigbee, MeshCore на LoRa. Что не имеет открытого API - ревершу и пишу интеграцию сам.

### 📡 MeshCore Kazakhstan

<a href="https://t.me/MeshCoreKZ"><img src="https://img.shields.io/badge/MeshCore_KZ-Telegram-2CA5E0?style=for-the-badge&logo=telegram&logoColor=white" /></a>
<img src="https://img.shields.io/badge/868_MHz-LoRa-2E8B57?style=for-the-badge&logo=signal&logoColor=white" />

Поддерживаю децентрализованную mesh-сеть **MeshCore** в Алматы вместе с большим комьюнити.
Текстовая связь без интернета, без операторов и без инфраструктуры - на дистанции до 100 км.
Ноды на Heltec V3, свои репитеры, мост в Telegram.

**[Присоединяйтесь -> t.me/MeshCoreKZ](https://t.me/MeshCoreKZ)**
